# 1688 Telegram Bot

Присылает в Telegram товары с 1688.com, которые прошли фильтр:
низкая цена + хороший рейтинг + много отзывов/продаж. Бренд и список
запросов настраиваются прямо командами/кнопками в Telegram.

## Как это работает

1. Каждые 30 минут GitHub Actions запускает `main.py`.
2. Сначала бот проверяет новые сообщения/нажатия кнопок в Telegram и
   обрабатывает команды (см. ниже) — добавление запросов, выбор бренда,
   разовый поиск.
3. Затем выполняет плановый поиск по сохранённому списку запросов через
   провайдера данных (`providers/tmapi.py`, сервис TMAPI), с учётом
   выбранного бренда.
4. Фильтрует по цене, рейтингу и числу отзывов, берёт самые дешёвые
   (по умолчанию — 30% дешевле остальных) и отправляет в Telegram.
5. Запоминает, что уже отправляло (`seen_items.json`), и своё состояние —
   список запросов, бренд, оффсет Telegram (`state.json`) — коммитит эти
   файлы обратно в репозиторий, чтобы не терять их между запусками.

## Команды в Telegram

| Команда | Что делает |
|---|---|
| `/help` | список команд |
| `/addquery <текст>` | добавить запрос в постоянный поиск, например `/addquery термос` |
| `/removequery <номер>` | убрать запрос (номер смотрите в `/queries`) |
| `/queries` | показать текущий список запросов и бренд |
| `/brand` | выбрать бренд кнопками (из secret `BRANDS_LIST`) |
| `/setbrand <текст>` | задать бренд вручную, если его нет в кнопках |
| `/clearbrand` | сбросить бренд — искать без привязки к нему |
| `/search <текст>` | разовый поиск прямо сейчас, без сохранения в список |

Если бренд выбран, он подставляется в начало каждого запроса
(`Nike` + `кроссовки` → ищет `Nike кроссовки`).

## Почему TMAPI, а не прямой доступ к 1688

У 1688 нет простого публичного API для обычного пользователя — их
официальный Open API требует бизнес-аккаунт продавца (часто с китайским
юрлицом), а прямой скрапинг сайта нестабилен и может блокироваться.
TMAPI — сторонний сервис, который уже легально агрегирует данные 1688 и
отдаёт их по REST API с пробным бесплатным тарифом. Если у вас уже есть
доступ к другому провайдеру (Superbuy Open API, CSSBuy и т.п.) — замените
`providers/tmapi.py` на свой класс с тем же интерфейсом `search()`.

## Настройка

### 1. Создайте Telegram-бота
- Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
- Узнайте свой `chat_id`: напишите боту любое сообщение, затем откройте
  `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id": ...}`.

### 2. Получите ключ TMAPI
- Зарегистрируйтесь на https://www.tmapi.top, возьмите API-ключ.
- **Важно:** перед боевым запуском проверьте актуальный формат ответа их
  API (может отличаться от того, что предполагает код) и при необходимости
  поправьте `_normalize_item` в `providers/tmapi.py`.

### 3. Выложите проект на GitHub
- Создайте приватный репозиторий, залейте туда все эти файлы.

### 4. Добавьте секреты
`Settings → Secrets and variables → Actions → New repository secret`:

| Секрет | Описание | Пример |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота от BotFather | `123456:ABC-DEF...` |
| `TELEGRAM_CHAT_ID` | ваш chat_id | `123456789` |
| `TMAPI_KEY` | ключ TMAPI | `xxxx` |
| `BRANDS_LIST` | *(необязательно)* бренды для кнопок `/brand`, через запятую | `Nike,Adidas,Xiaomi` |
| `MAX_PRICE_CNY` | *(необязательно)* макс. цена в юанях | `150` |
| `MIN_RATING` | *(необязательно)* мин. рейтинг из 5 | `4.6` |
| `MIN_REVIEWS` | *(необязательно)* мин. отзывов/продаж | `200` |

Список запросов больше не задаётся секретом — добавляйте их прямо в
Telegram командой `/addquery`. Пороги по умолчанию уже разумные: цена до
150¥, рейтинг от 4.6, отзывов/продаж от 200, берутся самые дешёвые 30% из
прошедших фильтр.

### 5. Запустите
- Вкладка **Actions** → workflow **"1688 bot run"** → **Run workflow**
  (первый запуск вручную).
- Напишите боту `/addquery термос` (и что вам ещё нужно) — список сохранится.
- Дальше бот сам проверяет Telegram и ищет каждые 30 минут.
- Расписание меняется в `.github/workflows/run.yml` (строка `cron`, формат —
  стандартный cron: `*/N * * * *` — раз в N минут, `0 */3 * * *` — раз в 3 часа
  и т.п.). Чем реже — тем меньше минут Actions тратится, но и реакция на
  команды в Telegram будет медленнее (до N минут задержки).

### Важно про лимит GitHub Actions
Раз в 30 минут — это ~1500 минут работы в месяц, укладывается в бесплатный
лимит приватных репозиториев (2000 мин/мес). Если решите вернуть более частый
запуск — либо сделайте репозиторий **публичным** (Actions бесплатны без
лимита; секреты всё равно останутся скрытыми, а `state.json`/`seen_items.json`
будут видны всем — там нет ничего чувствительного, только тексты запросов),
либо следите за расходом минут в Settings → Billing.

## Локальный запуск (для отладки)

```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN=...
export TELEGRAM_CHAT_ID=...
export TMAPI_KEY=...
export SEARCH_QUERIES="термос;наушники"
python main.py
```

## Что можно донастроить дальше
- Заменить провайдера данных, если TMAPI не подойдёт.
- Добавить фильтр по категориям / исключение слов из заголовка.
- Присылать не текстом, а фото товара (`sendPhoto` вместо `sendMessage`).
- Хранить `seen_items.json` не в репозитории, а во внешнем хранилище,
  если не хочется, чтобы бот коммитил в репо сам.
